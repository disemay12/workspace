- [x] `src/lib/pptxBuilder.ts`: сборка презентации из Markdown/текста — слайды по `#`-заголовкам, `---` как разрыв, списки/абзацы/код в тело, таблицы Markdown в настоящие таблицы PowerPoint, 16:9, тема Office; подключено к конвертеру (`md/txt/html/docx → pptx`) и к списку форматов.
