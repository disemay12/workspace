# WorkSpace

Автономный настольный рабочий кабинет: документы, таблицы, презентации, код и заметки
в одном окне — с персональным AI-ассистентом по вашему API-ключу.

Приложение не требует установки Microsoft Office и работает офлайн: все редакторы
встроены, ключи хранятся только на вашем компьютере.

## Скачать

Готовая portable-сборка для Windows x64 — в разделе
[Releases](https://github.com/disemay12/workspace/releases/latest).

## Возможности

### Файловый менеджер и вкладки
- Древовидный проводник рабочей папки с ленивой загрузкой каталогов.
- Фильтр по имени, создание / переименование / удаление файлов и папок.
- Множественные вкладки с индикатором несохранённых изменений (`•`).
- Один клик по файлу — предпросмотр без правки, двойной клик — редактирование.
  Предыдущий предпросмотр закрывается сам.
- Быстрый переход к файлу `Ctrl+P` (с историей недавних) и `Ctrl+Tab` между вкладками.
- Режим разделённого экрана: два документа рядом с перетаскиваемой границей.
- «Сохранить как…» (`Ctrl+Shift+S`): смена имени, папки и формата с конвертацией
  `.md` → `.docx`, `.csv` → `.xlsx`, `.docx` → `.md/.txt/.html/.pdf` и обратно.
  То же умеет AI-ассистент (`save_as`, `convert_file`).

### Редакторы по форматам

| Категория | Форматы | Реализация |
|---|---|---|
| Текст и логи | `.txt` `.log` `.ini` `.cfg` `.env` `.bat` `.sh` | Monaco Editor: подсветка, перенос строк, миникарта, поиск/замена по RegEx |
| Код и конфиги | `.json` `.yaml` `.xml` `.csv` `.sql` `.py` `.js` `.ts` `.html` `.css` и др. | Monaco Editor со 100+ языками и воркерами подсветки |
| Заметки и документы | `.md` `.markdown` `.note` | Markdown-редактор: код / предпросмотр / разделённый режим, слэш-команды `/` |
| Таблицы | `.xlsx` `.xls` `.csv` `.tsv` | Сетка с формулами, несколькими листами, объединением ячеек, форматированием, диаграммами, отменой и экспортом в CSV. Заливка, шрифт, границы и числовые форматы сохраняются как нативные стили Excel; ширина колонок подбирается по содержимому, чтобы в Excel текст не обрезался |
| Документы Word | `.docx` `.doc` | Редактор OOXML: заголовки, списки, таблицы, картинки, стили, колонтитулы, разрывы секций, TOC, сноски, комментарии и закладки. Правки сохраняются в исходный пакет, а не пересобирают файл целиком |
| Презентации | `.pptx` `.ppt` | Редактор: текст, слайды, заметки докладчика, изображения и макеты; новые файлы создаются из валидного пустого шаблона, сохранение — патчем slide XML |
| Изображения | `.png` `.jpg` `.svg` `.webp` и др. | Встроенный просмотрщик |

### Кодировки
Поддержка UTF-8, UTF-16 (с автоопределением по BOM), Windows-1251 / ANSI, KOI8-R,
ISO-8859-5. Кодировку можно сменить из редактора — файл перечитывается заново.
CSV/TSV сохраняются в UTF-8 с BOM, чтобы русский Excel открывал их без «кракозябр».
Запись выполняется атомарно (через временный файл), чтобы сбой не повредил данные.

### Обновления
Кнопка «Проверить обновление» в настройках и автоматическая проверка при запуске
предлагают новую версию с GitHub Releases. Обновление заменяет папку программы
на месте, без папок версий; API-ключи и настройки в `%APPDATA%\WorkSpace`
сохраняются и дополнительно резервируются перед установкой.

### AI-ассистент (BYOK — свой ключ)
Поддерживаются провайдеры: **OpenAI**, **Anthropic Claude**, **Google Gemini**,
**DeepSeek**, **OpenRouter**, **OpenCode (Go)**, **Ollama**, **Starimg AI** и любой
OpenAI-совместимый endpoint. OpenCode Go использует базовый URL
`https://opencode.ai/inference/go/openai/v1`; для pay-as-you-go укажите
`https://opencode.ai/inference/openai/v1` в поле «Базовый URL API».

- **Боковой чат** — стриминг ответов в реальном времени, прикрепление открытого
  документа или выделенного фрагмента к запросу, подсветка кода в ответах.
- **Инлайн-копилот `Ctrl+K`** — правка прямо в тексте: переписать, сократить,
  перевести, объяснить, продолжить. Результат показывается в виде diff
  с подтверждением или отклонением.
- **Помощник по таблицам** — генерация формул Excel по описанию словами.
- **Анализ логов** — поиск `ERROR` / `FATAL`, объяснение причин и шаги исправления.
- **Роли ассистента** — системные промты для общих задач, Excel, логов, редактуры, кода.
- **Агентная правка документов** — при открытом Word, Excel, PowerPoint или Markdown
  ассистент через function calling читает структуру и вносит правки нативными
  инструментами: блоки и диапазоны, таблицы, стили, колонтитулы, изображения,
  слайды, макеты, заметки, листы и ячейки. Каждый ответ атомарен, показывает diff,
  попадает в историю и откатывается одной кнопкой.
- **Word** — заголовки, списки, таблицы (строки, столбцы, объединение, ширина,
  границы), картинки по пути/data URL/http, поля PAGE/NUMPAGES, TOC с пересборкой
  кэша, сноски, комментарии, закладки, пользовательские стили, колонтитулы,
  разрывы страниц и секций.
- **PowerPoint** — замена текста фигур, добавление и удаление слайдов, порядок,
  текстовые фигуры, изображения, заметки докладчика и смена макета.
- **Excel** — чтение/запись ячеек и формул, листы, строки/столбцы, merge/unmerge,
  форматирование диапазона и панель AI-diff с отменой.
- **Markdown** — `md_read`, замена, append, полная замена, заголовки, списки,
  ссылки и таблицы; история изменений с diff.
- **Дополнительные файлы** — `read_document` читает другой файл workspace,
  `write_document` пишет `.docx`, `.xlsx`, `.md` и `.txt` только после явного
  разрешения «Доп. файлы: запись». Прочитанные файлы показываются чипами.
- **Прозрачность агента** — чипы вызванных инструментов сохраняются в сообщении,
  панель плана показывает текущий шаг; без прав записи модели передаётся только чтение.
- **Вставка в редактор** — «Вставить код» в позицию курсора или «Заменить документ».

Ключи шифруются (AES-GCM через Web Crypto) и сохраняются локально; в открытом виде
не покидают машину и отправляются только выбранному провайдеру.

#### Быстрый старт с локальным файлом секретов

Если ключ лежит в файле `secrets.local.ps1` в корне проекта, его можно не вводить
руками: **Настройки → Провайдер → «Импортировать»**. Ожидаемые переменные:

```powershell
$env:API_BASE_URL = "https://ai.starimg.ru/v1"
$env:API_KEY      = "sk-..."
$env:TEXT_MODEL   = "deepseek-v4.1-flash"
```

Файл добавлен в `.gitignore` и никогда не попадает в репозиторий. Импортируется
только `API_KEY`; остальные секреты в файле (например, токены Notion или Telegram)
не читаются, о чём интерфейс предупреждает. Ключ по умолчанию замаскирован —
он передаётся в интерфейс только по нажатию кнопки импорта и сразу сохраняется
в зашифрованное хранилище.

> **Важно:** если ключ когда-либо попадал в чат, коммит или общий доступ —
> смените его у провайдера. Перенос ключа в переменную окружения не отменяет утечку.

## Запуск

Требуется Node.js 20+.

### Готовые .bat-файлы (Windows)

Двойной клик по нужному файлу — ничего вводить не требуется. Скрипты сами
снимают переменную `ELECTRON_RUN_AS_NODE`, из-за которой Electron падает
с ошибкой `Cannot read properties of undefined (reading 'isPackaged')`,
и при необходимости доустанавливают зависимости.

| Файл | Назначение |
|---|---|
| **`start-dev.bat`** | Запуск в режиме разработки (Vite + Electron, горячая перезагрузка) |
| **`start-prod.bat`** | Сборка и запуск готового приложения из папки `dist` |
| **`run-tests.bat`** | Полный прогон всех проверок, результат в `final-report.txt` |
| **`build.bat`** | Только сборка, без запуска |
| **`check-env.bat`** | Диагностика: Node, зависимости, Electron, ключи, переменные окружения |

Если что-то не запускается — начните с `check-env.bat`: он показывает,
что именно настроено неверно и как это исправить.

### Командная строка

```bash
npm install
npm run dev      # запуск с горячей перезагрузкой (Vite + Electron)
```

Production-сборка и запуск:

```bash
npm run build
npm start
```

Проверка типов:

```bash
npm run typecheck
```

Полный прогон проверок (типы, сборка, IPC, рендеринг, AI). Часть сценариев
требует настроенный API-ключ; `integration-check` может зависать в среде без сети:

```bash
npm run checks
```

> **Примечание для ручного запуска.** Если в системе задана переменная
> `ELECTRON_RUN_AS_NODE`, Electron запустится как обычный Node и упадёт.
> Снимите её в текущем окне терминала:
> ```powershell
> Remove-Item Env:\ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
> ```
> `.bat`-файлы делают это автоматически.

### Сборка portable-версии (Windows)

```bash
npm run build:portable   # WorkSpace\WorkSpace.exe + app.asar
npm run pack:release     # dist\WorkSpace-<version>-win-x64.zip
```

Рекомендуемая папка запуска — `C:\WorkSpace` (не из временных и не из
ограниченных каталогов). Если Windows выдаёт предупреждение о низком уровне
целостности, приложение проверит реальную запись в `Documents` и покажет
предупреждение только при фактической ошибке сохранения.

### Ключевые решения

- **Безопасность процессов.** `nodeIntegration: false`, `contextIsolation: true`;
  рендерер общается с файловой системой только через явный список IPC-методов.
- **AI-запросы идут через главный процесс.** Браузерный `fetch` подчиняется
  политике CORS: часть OpenAI-совместимых шлюзов не отдаёт заголовок
  `Access-Control-Allow-Origin`, и Chromium прерывает ответ с `net::ERR_FAILED`
  (в интерфейсе это выглядело как «Не удалось подключиться»). Поэтому запросы
  выполняются в главном процессе через модуль `net`, который не подчиняется
  CORS, а ответ стримится в рендерер событиями IPC. Ключ передаётся при каждом
  запросе и в главном процессе не сохраняется.
- **Content-Security-Policy.** Ресурсы загружаются только локально; Monaco
  подключается из бандла, а не с CDN, поэтому приложение работает офлайн.
- **Design tokens.** Цвета заданы CSS-переменными внутри `@layer base`
  (`src/index.css`) и переключаются классом `.dark`. Объявления намеренно
  находятся в слое: вне слоёв они перекрывали бы утилиты Tailwind.
- **Атомарная запись.** Файл пишется во временный файл и затем переименовывается.
- **Оптимизация больших файлов.** Для файлов > 1,5 МБ Monaco автоматически
  отключает миникарту, свёртку и подсветку вхождений.

## Ограничения

- `.doc` (Word 97-2003) читается только как текст: оформление, шрифты и вёрстка
  таблиц не переносятся. Сохранение создаёт `.docx` рядом — исходный `.doc`
  не изменяется. Устаревший `.ppt` не разбирается, нужен `.pptx`.
- `.docx` сохраняется патчем OOXML: меняется `word/document.xml`, остальные части
  пакета (стили, нумерация, колонтитулы, сноски, комментарии, media) сохраняются.
  Неподдерживаемые объекты Word (SmartArt, content controls, сложные поля)
  показываются read-only и не редактируются.
- `.pptx` редактируется патчем slide XML; это не полноценный дизайнер PowerPoint:
  произвольная графика и анимации не создаются.
- Комментарии и сноски пока добавляются, но существующие не редактируются.
- Номера страниц в TOC обновляет Word; приложение пересобирает только кэш заголовков.
- Формулы в таблицах вычисляются встроенным движком: широкая поддержка функций,
  диапазонов и ссылок на листы, но не полный пересчёт и не все функции Excel.
- Ключ API шифруется средствами Windows и привязан к профилю: при переносе
  portable-папки на другой компьютер его нужно ввести заново (или импортировать
  из `secrets.local.ps1` — приложение предложит это само).
