# Requirements Checklist: Сайт скачивания WorkSpace

**Feature**: `001-download-site` · проверка спецификации перед реализацией.

## Полнота требований

- [x] FR-001 статика в `docs/`, без сборочного шага
- [x] FR-002 только относительные пути (подпуть `/workspace/`, `file://`)
- [x] FR-003 первый экран: название, одно предложение, действие при 1280×800
- [x] FR-004 кнопки ведут на ассет последнего релиза и на страницу релизов
- [x] FR-005 описание продукта: форматы, AI (BYOK), кодировки, обновления, клавиши, требования, ограничения
- [x] FR-006 не менее пяти скриншотов реального интерфейса с подписями и `alt`
- [x] FR-007 кадры сняты с чистого профиля и синтетической папки, без личных файлов
- [x] FR-008 скрипты пересоздают демо-данные и кадры
- [x] FR-009 `title`, `description`, Open Graph, `lang="ru"`, favicon, без внешних запросов
- [x] FR-010 контент виден без JavaScript, анимации уважают `prefers-reduced-motion`
- [x] FR-011 `.nojekyll`, workflow Pages, инструкция включения
- [x] FR-012 нет выдуманных метрик, отзывов, логотипов и цитат

## Проверяемость

- [x] Каждое утверждение страницы сверено с `README.md`, `src/`, `electron/` или GitHub API релиза
- [x] Версия `1.0.15` и размер `264 177 605` Б (252 МБ) взяты из ответа GitHub API, а не по памяти
- [x] Ссылки на скачивание указывают на существующий ассет `WorkSpace-1.0.15-win-x64.zip`

## Готовность к публикации

- [x] `sloplint.mjs --render`: 0 FAIL, 0 REFLEX, 0 WARN
- [x] Проверены 375, 1280×800, 1440×900, 1920×1080
- [x] Нет абсолютных локальных путей в `docs/index.html` и `docs/styles.css`
- [x] Шрифты и изображения лежат в репозитории, страница не ходит в сеть
- [ ] Pages включён в настройках репозитория, страница открывается по адресу проекта
