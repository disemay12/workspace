WorkSpace — рабочий стол для документов, таблиц и презентаций (Windows x64)
=====================================================================

Установка
---------
1. Распакуйте архив в удобное место (например, C:\WorkSpace).
2. Запустите WorkSpace.exe.
3. Обновление: распакуйте новую версию поверх старой папки — настройки
   и документы не пострадают, они лежат вне папки программы.

Если Windows SmartScreen предупреждает о запуске:
  «Подробнее» → «Выполнить в любом случае».

Где лежат настройки
-------------------
Папка программы одноразовая: её можно удалить или перезаписать новой версией.

  %APPDATA%\WorkSpace\
    ai-settings.json      провайдер AI, модель, зашифрованные ключи
    secrets.local.ps1     шаблон для API-ключа (создаётся при первом запуске)
    gdrive.json           авторизация Google (если подключали)
    workspace-session.json последняя папка и закреплённые места
    Preferences, Cache…   служебные файлы Chromium

Первое создание выполняется автоматически: чего нет — появится с базовыми
значениями. Удалять эту папку стоит только если нужен полный сброс.

Возможности
-----------
- Редакторы Word, таблицы Excel/CSV, презентации, PDF, изображения и видео.
- Редактор кода (Monaco) и Markdown с предпросмотром, диаграммы Mermaid.
- Word: заголовки, списки, таблицы, картинки, стили, колонтитулы, разрывы
  секций, TOC, сноски, комментарии и закладки. Правки сохраняются в исходный
  .docx-пакет, а не пересобирают файл целиком.
- PowerPoint: редактор на модели документа — темы (цвета схемы и шрифты),
  фигуры с перетаскиванием и порядком наложения, rich-text, таблицы, фон,
  заметки, переходы, режим показа, поиск/замена, отмена и экспорт PDF.
  Любой текстовый файл собирается в презентацию по заголовкам (# — слайд).
- Excel-редактор: формулы, обработка ошибок, числовые форматы, диаграммы,
  условное форматирование, сводные таблицы, фильтры, вставка из буфера.
  Заливка, шрифт и границы сохраняются как нативные стили Excel.
  Большие .xlsx/.csv открываются окнами строк: разбор идёт в фоновом потоке,
  книга не пересобирается на каждое нажатие.
- Масштаб полотна Word и сетки Excel — Ctrl+колесо мыши (50–200%).
- Оформление настраивается: тема (как в системе / тёмная / светлая), акцентный
  цвет, плотность, масштаб интерфейса 85–130 %, режим «меньше анимации».
- Автосохранение: несохранённые документы раз в 2 секунды сохраняются в профиль
  (%APPDATA%\WorkSpace\autosave). После падения или закрытия окна снимки
  поднимаются обратно в вкладки с пометкой «есть изменения», после сохранения
  файла снимок удаляется.
- Уведомления: тихие тосты и короткий сигнал (стук/мягкий), правила по типам
  событий, громкость и расписание тишины; системные звуки Windows не играются.
- Диаграммы в настоящем .xlsx: файл открывается в Microsoft Excel.
- Встроенный терминал PowerShell.
- AI-ассистент: OpenAI, Anthropic, Gemini, DeepSeek, OpenRouter, Ollama и
  OpenAI-совместимые серверы. Ключи хранятся в профиле пользователя.
- Агентная правка Word/Excel/PowerPoint/Markdown: инструменты, атомарные
  транзакции, diff, история и откат; дополнительные файлы — только после
  явного разрешения записи.
- Видеоредактор: обрезка, скорость, сжатие, приближение кадра (100–800 % в
  превью, масштаб при экспорте), прогресс и отмена, публикация на YouTube.
- Экспорт изображений на ImgBB, Freeimage и Япикс: альбомы собираются пачками
  по лимитам сервиса, ссылки копируются в буфер.
- Google Drive и YouTube подключаются раздельно, с мини-гайдом и проверкой
  доступа; загрузка больших файлов на Диск идёт кусками с прогрессом.
- Открытие файла из контекстного меню Windows раскрывает дерево до него.
- AI управляет презентацией целиком: слайды (дублировать, скрыть, макет,
  размер, переход, фон), текст по run'ам и спискам, фигуры (вставка, геометрия,
  поворот, заливка, контур, тень, порядок), таблицы, темы, поиск-замена, показ
  и экспорт PDF. Из текста собирается .pptx по заголовкам.
- AI управляет изображениями: поворот, отражение, обрезка, масштаб, смена
  формата (png/jpeg/webp), сжатие до заданного веса, миниатюры, пакетная
  обработка списка файлов, вставка в Word/слайд, загрузка на хостинги.
- AI управляет видео: обрезка, скорость (включая сегменты), сжатие, без звука,
  кадрирование; извлечение звука в mp3/aac, кадры-миниатюры, конвертация
  mp4/webm/gif, GIF из отрезка, публикация на YouTube. Без ffmpeg инструменты
  возвращают понятную ошибку, превью продолжает работать.

Ограничения
-----------
- AI работает с вашим ключом и вашим провайдером; без ключа — только текст.
- .doc читается как текст; .ppt не поддерживается, нужен .pptx.
- .docx сохраняется патчем OOXML; SmartArt, content controls и сложные поля
  показываются read-only.
- .pptx редактируется на модели документа; SmartArt, произвольная анимация и
  диаграммы показываются read-only. Заметки докладчика в презентации,
  собранные из текста, не переносятся.
- Комментарии и сноски добавляются, существующие не редактируются.
- Номера страниц в TOC обновляет Word.
- Настройки хранятся в %APPDATA%\WorkSpace и не синхронизируются между ПК.
- Ключи API в архив не входят: впишите их в настройках приложения.

Требования
----------
- Windows 10/11 x64.
- Microsoft Office — по желанию.
- Для работы с видео нужен ffmpeg в PATH (сборка подскажет, если его нет).
- Рекомендуемая папка запуска — C:\WorkSpace. Если Windows предупреждает
  о низком уровне целостности, приложение проверит реальную запись в Documents
  и покажет предупреждение только при фактической ошибке сохранения.

Если что-то не работает
-----------------------
- Закройте все окна WorkSpace и запустите WorkSpace.exe заново.
- Сброс настроек: переименуйте папку %APPDATA%\WorkSpace.
- Полный сброс: удалите папку %APPDATA%\WorkSpace (документы не затрагиваются).
- PDF: превью страниц, поиск по тексту, поворот, удаление, перестановка и
  извлечение страниц, вшитые аннотации (маркер и заметки, включая кириллицу).
- Профили промптов (документы, код, данные, презентации) с редактором во
  вкладке «Промпт»; правки AI можно применять выборочно по операциям.
- Второе окно и общая раскладка: панели и открытые вкладки восстанавливаются
  при старте и синхронизируются между окнами.
- Тяжёлые редакторы грузятся по требованию — окно открывается быстрее.
