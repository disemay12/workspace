# Архитектурный и практический план создания WorkSpace

> **Цель проекта:** Создать автономный, современный и высокопроизводительный цифровой рабочий кабинет (WorkSpace) со встроенными редакторами для всех видов документов (Rich Text, Markdown, Notepad/код, Word, Excel, PowerPoint) без необходимости устанавливать сторонние офисные пакеты, а также с глубокой интеграцией персонального AI-ассистента по API-ключу.

---

## 1. Концепция и ключевые требования

1. **Единое рабочее пространство (All-in-One):**
   - Древовидный файловый менеджер проекта / папок на компьютере.
   - Система вкладок (Tabs) и режим разделенного экрана (Split View: бок о бок или сверху/снизу).
   - Быстрый поиск по содержимому всех документов (Full-Text Search / Quick Open `Ctrl+P`).
   - Автосохранение, история версий (Local History), откат изменений.

2. **Работа с текстовыми документами (Современный Rich Text & Notes):**
   - Блочный редактор в стиле Notion / Craft (заголовки, списки, чек-листы, цитаты, выноски-callout, таблицы, разделители, формулы Math/KaTeX).
   - Полноценная поддержка Markdown (двусторонняя синхронизация: WYSIWYG + исходный код).
   - Слэш-команды (`/`) для быстрой вставки блоков и вызова AI.

3. **Поддержка всех форматов Notepad (Plain Text / Code / Logs / Configs):**
   - Форматы: `.txt`, `.log`, `.ini`, `.cfg`, `.json`, `.yaml`, `.xml`, `.csv`, `.tsv`, `.bat`, `.sh`, `.py`, `.js`, `.ts`, `.html`, `.css`, `.sql` и любые произвольные текстовые файлы.
   - Движок на базе **Monaco Editor** (ядро VS Code):
     - Подсветка синтаксиса для 100+ языков.
     - Поддержка кодировок (UTF-8, UTF-16, Windows-1251 / CP1251 для старых русскоязычных файлов, ANSI).
     - Мини-карта (Minimap), номера строк, свертка кода (Code Folding), мультикурсоры.
     - Быстрый поиск и замена по регулярным выражениям (RegEx).
     - Оптимизация под открытие больших файлов (включая многомегабайтные `.log`).

4. **Встроенный офисный пакет (Office Suite без MS Office):**
   - **Электронные таблицы (Excel: `.xlsx`, `.xls`, `.csv`):**
     - Полноценный интерфейс таблиц (ячейки, формулы `=SUM`, `=VLOOKUP` и т.д., стили, объединение ячеек, автофильтры, сортировка, несколько листов).
     - Движок: **Univer Sheet** / **FortuneSheet** + **SheetJS**.
   - **Текстовые документы Word (`.docx`, `.doc`):**
     - Рендеринг и редактирование форматированного текста, таблиц, изображений и стилей `.docx` без MS Word.
     - Движок: **Univer Doc** / **docx-preview** + конвертер docx/HTML.
   - **Презентации PowerPoint (`.pptx`, `.ppt`):**
     - Просмотрщик слайдов с предпросмотром страниц, анимациями, навигацией и базовым редактированием текста на слайдах.
     - Движок: **Univer Slide** / **pptxjs** / рендерер слайдов.

5. **Интеграция нейросети по личному API (BYOK - Bring Your Own Key):**
   - Поддержка провайдеров: OpenAI (GPT-4o / GPT-4o-mini), Anthropic (Claude 3.5 Sonnet), Google Gemini (Gemini 1.5/2.0), DeepSeek, Groq, OpenRouter, а также локальных LLM (Ollama / LM Studio).
   - Безопасное локальное хранение ключей (ключи сохраняются только локально на машине пользователя).
   - **Сценарии использования AI:**
     - **Боковая панель (AI Chat Sidebar):** общение с ассистентом с учетом контекста открытого документа или выбранного фрагмента.
     - **Инлайн-копилот (`Ctrl+K` / `Cmd+K`):** редактирование прямо в тексте (переписать, сократить, исправить грамматику, продолжить мысль, сгенерировать блок).
     - **Помощник по таблицам:** генерация формул Excel по текстовому описанию («посчитай среднее по столбцу B, если в столбце C стоит "Да"`), анализ данных таблицы.
     - **Анализ файлов и RAG:** ответы на вопросы по загруженным документам, логам и спецификациям.

### Сравнение платформенных решений:
* **Рекомендуемый выбор: Tauri v2 (Rust + Webview2) или Electron:**
  - **Tauri v2:** Очень легкий вес (~15-20 МБ установщик вместо 150 МБ), минимальное потребление RAM, прямой нативный доступ к файловой системе Windows, высокая безопасность.
  - **Electron:** 100% совместимость с любыми Node.js библиотеками, максимальная простота сборки.
  - *Альтернатива на первом этапе:* Локальное Web/SPA-приложение на Vite + Node.js/Fastify сервере, которое можно запускать одной командой в браузере или сразу завернуть в Tauri/Electron.

## 3. Детальный план реализации по этапам

### Этап 1: Инициализация ядра и базового интерфейса (Core Foundation)
- [ ] **1.1. Настройка окружения проекта:**
  - Инициализация репозитория с TypeScript, Vite, Tailwind CSS и компонентной библиотекой (Shadcn UI / Radix Primitives).
  - Настройка структуры папок (`src/components`, `src/editors`, `src/services`, `src/hooks`, `src/types`).
- [ ] **1.2. Каркас рабочего пространства (Workspace Shell):**
  - Создание главного макета: левая боковая панель (Explorer), центральная рабочая область, правая панель (AI Assistant).
  - Сворачиваемые/раскрываемые панели с запоминанием размеров (Resizable Panels).
  - Поддержка светлой и темной темы (Dark / Light Theme).
- [ ] **1.3. Файловый проводник (File Tree) и менеджер вкладок (Tab System):**
  - Подключение локальной рабочей папки (Workspace Root).
  - Создание, переименование, удаление, перемещение файлов и папок.
  - Система множественных вкладок с индикатором несохраненных изменений (`dirty state`).
  - Механизм быстрого переключения файлов (`Ctrl+Tab`, `Ctrl+P`).

---

### Этап 2: Текстовый редактор Notepad & Code (Monaco Editor)
- [ ] **2.1. Интеграция Monaco Editor:**
  - Подключение `@monaco-editor/react`.
  - Автоматическое определение языка по расширению файла (`.txt`, `.log`, `.json`, `.xml`, `.ini`, `.yaml`, `.sql`, `.py`, `.js`, etc.).
- [ ] **2.2. Продвинутые возможности для Notepad-файлов:**
  - Поддержка смены кодировок (UTF-8, Windows-1251 / CP1251).
  - Перенос строк (Word Wrap переключатель).
  - Поиск и замена с поддержкой Regex и регистра.
  - Оптимизация производительности: виртуализация и ленивая подгрузка для больших лог-файлов.
  - Отображение строки состояния: строка/колонка, кодировка, тип окончания строк (CRLF/LF), размер файла.

---

### Этап 3: Современный редактор документов (Rich Text / Notes / Markdown)
- [ ] **3.1. Блочный редактор заметок (TipTap / BlockNote):**
  - Поддержка форматирования: жирный, курсив, зачеркнутый, код, цвет текста/фона.
  - Блоки: Заголовки (H1-H3), списки (маркированный, нумерованный, to-do чек-листы), цитаты, выноски (Callouts), таблицы, блоки кода с подсветкой.
  - Слэш-меню (`/`) для быстрой вставки любого элемента.
- [ ] **3.2. Markdown-интеграция:**
  - Возможность открывать `.md` файлы в визуальном режиме (WYSIWYG) или переключаться в режим исходного кода (Raw Markdown).
  - Экспорт документов в Markdown, HTML и PDF.

---

### Этап 4: Встроенный офисный пакет (Office Suite без MS Office)

#### 4.1. Электронные таблицы (Excel / Sheets: `.xlsx`, `.xls`, `.csv`)
- [ ] Интеграция движка таблиц (**Univer Sheets** или **FortuneSheet**).
- [ ] Парсинг и сохранение файлов через библиотеку **SheetJS (xlsx)** / нативные адаптеры Univer.
- [ ] Функционал:
  - Вычисление формул (математические, статистические, текстовые, логические).
  - Форматирование ячеек: числа, проценты, даты, валюты, границы, заливка, шрифты.
  - Поддержка нескольких листов в одном файле (вкладки снизу).
  - Сортировка данных и автофильтрация.
  - Экспорт и импорт без потери структуры.

#### 4.2. Текстовые документы Word (`.docx`, `.doc`)
- [ ] Интеграция просмотрщика и редактора Word-документов (**Univer Doc** или связка **docx-preview** + **Mammoth** / **TipTap DOCX Adapter**).
- [ ] Отображение стилей, заголовков, таблиц, списков и встроенных картинок.
- [ ] Возможность редактировать текст документа и сохранять обратно в `.docx`.

#### 4.3. Презентации PowerPoint (`.pptx`)
- [ ] Интеграция просмотрщика слайдов (компонент на базе **Univer Slide** или **pptxjs** / рендерер в SVG/Canvas).
- [ ] Полноэкранный режим показа презентации (Slide Show mode).
- [ ] Навигационная панель миниатюр слайдов (Thumbnail List).
- [ ] Базовое редактирование текстовых полей на слайдах с сохранением изменений.

---

### Этап 5: Подсистема Искусственного Интеллекта (Personal API)

- [ ] **5.1. Менеджер API-провайдеров и настроек (Settings):**
  - Экран настроек для ввода ключей:
    - **OpenAI** (модели: GPT-4o, GPT-4o-mini, o1, o3-mini)
    - **Anthropic Claude** (Claude 3.5 Sonnet, Claude 3.5 Haiku)
    - **Google Gemini** (Gemini 1.5 Flash, Gemini 1.5 Pro, Gemini 2.0)
    - **DeepSeek** (DeepSeek-V3, DeepSeek-R1)
    - **OpenRouter** (универсальный шлюз к 100+ моделям)
    - **Custom / Local endpoint** (любой совместимый с OpenAI URL, например Ollama `http://localhost:11434/v1`).
  - Выбор активной модели по умолчанию, настройка системного промта (System Prompt) и температуры.
  - Локальное безопасное хранение ключей в защищенном хранилище.

- [ ] **5.2. AI Chat Sidebar (Боковой чат):**
  - Стриминг ответов (Real-time Streaming).
  - Кнопка «Добавить контекст текущего файла» (прикрепляет содержимое открытого документа к запросу).
  - Подсветка кода в ответах с кнопкой «Вставить в редактор» (Insert at cursor).
  - Сохранение истории диалогов с возможностью очистки.

- [ ] **5.3. Инлайн-копилот (Inline Assistant `Ctrl+K`):**
  - Всплывающее окно над выделенным текстом в любом редакторе:
    - *«Исправь ошибки и улучши стиль»*
    - *«Переведи на английский / русский»*
    - *«Сделай краткую выжимку (Summary)»*
    - *«Объясни этот фрагмент / этот лог»*
    - *«Продолжи текст»*
  - Быстрое принятие (Accept) или отклонение (Reject) предложенных изменений в режиме Diff.

- [ ] **5.4. Специализированные AI-инструменты для таблиц и офиса:**
  - Генератор формул для Excel: ввод естественным языком -> готовая формула в ячейку.
  - Автоматический анализ лог-файлов: выявление `ERROR`, `FATAL`, аномалий и причин сбоев.

## 5. Первые шаги для старта реализации

1. **Утверждение технологического стека:**
   - Рекомендуемый вариант: **Vite + React + TypeScript + Tailwind CSS / Shadcn UI** с последующей упаковкой в **Tauri v2** (Windows Native, ультралегкий вес).
2. **Создание структуры репозитория и базового каркаса (Этап 1).**
3. **Подключение Monaco Editor и BlockNote для закрытия задач Notepad и заметок (Этапы 2-3).**
4. **Интеграция Univer / SheetJS для поддержки Excel, Word и PowerPoint (Этап 4).**
5. **Подключение модуля AI с экраном настроек API-ключей (Этап 5).**
